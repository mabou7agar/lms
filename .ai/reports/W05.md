# W05 Report — Commerce Mega-Wave (Commerce Foundation)

## Scope (implemented)
Unified commerce stack in `apps/api/app/Contexts/Commerce` + `apps/web`:
- Products/prices, Cart, Coupons/Promotions, Checkout, Orders, Invoices, Credit Notes, Refunds.
- Subscriptions (plans/prices/changes; subscribe/renew/grace/cancel/reactivate/expire).
- Entitlements (EntitlementPort in the Shared kernel; EntitlementAdapter).
- Payments behind `Contracts/PaymentGateway` — Fake default + adapters: Paymob, Moyasar, HyperPay, Tap, Amazon Payment Services, Stripe. Webhooks signature-verified in-adapter.
- Tax behind `Contracts/TaxCalculator` (server-authoritative, integer minor-unit half-up apportionment).
- Commerce analytics; learner billing portal; admin commerce (Filament resources).
Excluded by design: Search / Discussions / Reviews / Wishlist / Gamification.

## Key implementation facts
- Money = integer minor units throughout. Idempotency on payments/orders/refunds/subscriptions/webhooks.
- Gateway I/O outside DB transactions; order + coupon redemption COMMIT before any gateway call; compensating transaction on gateway failure.
- Invoice lines snapshot on OrderPaid; credit note on full refund.
- 263 backend files + 3 frontend files (i18n dictionaries, checkout test, admin-guard).
