# W07 Report — Independent QA & Verification

## Method
Parallel read-only adversarial auditors (admin/API-contract, security, commerce/concurrency,
learner/instructor, data-integrity, test-quality) → deduped to reproducible defects only → fixed
continuously, re-running affected gates per batch.

## Verified fixes (all reproducible)
1. **Admin console crash** — 5 controllers (AdminOrder, AdminSubscription, AdminCoupon, CreditNote, learner Subscription) wrapped a paginator in `ApiResponse::success(...::collection())`, dropping `meta`/`links`; frontend read `data.meta.*` → TypeError. → `ApiResponse::paginated()`.
2. **Dunning crashed on Postgres** — `PaymentRecoveryService::record()` used `lockForUpdate()->max()` (Postgres rejects FOR UPDATE + aggregate). Zero tests, never caught. → locked ordered `value()` read + regression test.
3. **Completed learners locked out of assessments** — W06 gate used active-only `isEnrolled`. → new `CourseEnrollmentPort::hasCourseAccess` (active OR completed); StartAttemptAction uses it.
4. **Partial refund treated as full (webhook)** — `applyRefund` flipped any Paid order to Refunded. → transition only when cumulative succeeded refunds ≥ order total.
5. **Charge-ledger corruption on retries** — `payment.succeeded` flipped every charge row Succeeded. → settle only the confirming charge, supersede stale pending ones.
6. **Invoice lines ignored the coupon discount** — didn't reconcile to the invoice total; credit note over-credited. → apportion discount + VAT across lines.
7. **Invoice-number race** — `count()+1`, unlocked → collisions/gap reuse. → locked max-based allocation.
8. **Coupon-cap escape via dunning** — failed-then-dunning-paid coupon order kept the discount uncounted. → idempotent `ReconcileCouponRedemptionOnOrderPaid` listener.
9. **Certificate forgery** — legacy `/lessons/{id}/progress` accepted client `status:"completed"`, bypassing required-assignment/blocks. → enforce `LessonCompletionPolicy`.
10. **Forced video completion** — `VideoProgressService` used a client `duration_seconds` fallback as completion basis. → server-authoritative only.
11. **Coupon-scope contract mismatch** — form offered `plans`, backend enum rejects (422). → removed from frontend.
12. **Unclamped `per_page`** — OrganizationController. → clamp ≤100.
13. **OTP guess ceiling** — `attempts` incremented but never enforced. → burn code at ceiling.
14. **Mobile drawer never closed on navigation** (all AppShell areas). → pathname effect.
15. **Instructor-only nav leaked on /teach/apply**. → neutral account nav for that route.
16. **Double `aria-current`** in the sidebar (parent+child). → longest-prefix active only.
17. **Hardcoded a11y names** (AppShell drawer) + **dead footer language control**. → i18n / removed.
